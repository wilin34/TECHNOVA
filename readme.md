Sitio web corporativo oficial de **TechNova Solutions**, agencia de consultoría tecnológica y desarrollo de software especializada en Desarrollo Web, Computación en la Nube y Ciberseguridad.

---

## 📖 Descripción del Proyecto

TechNova Solutions carecía de presencia web oficial, lo que generaba pérdida de credibilidad, procesos de venta ineficientes y oportunidades perdidas 24/7. Este proyecto resuelve esos problemas mediante una plataforma web moderna, responsiva e integrada con Inteligencia Artificial.

---

## 🚨 Planteamiento del Problema

La empresa enfrentaba los siguientes conflictos operativos y comerciales:

1. **Pérdida de Credibilidad:** Los clientes potenciales no encontraban un sitio oficial al buscarla en internet.
2. **Proceso de Ventas Ineficiente:** Solicitudes dispersas por WhatsApp y llamadas telefónicas, sin canal automatizado.
3. **Falta de Información:** Prospectos desconocían el portafolio exacto de servicios.
4. **Pérdida de Oportunidades 24/7:** Dependencia exclusiva de horarios de oficina.

---

## 💡 Solución Implementada

Se desarrolló una página web responsiva con las siguientes características:

- ✅ **Diseño Futurista:** Tipografía **Orbitron Bold** y paleta de colores basada en degradados azules/negros (estilo ORIGINS).
- ✅ **Portafolio Claro:** Sección detallada de servicios (Desarrollo Web, Nube, Ciberseguridad).
- ✅ **Formulario Inteligente con IA:** Integración de **Groq API** (Llama 3.3) que analiza la solicitud del cliente y genera una respuesta preliminar automática.
- ✅ **Optimización PWA:** Favicon completo, manifest y metadatos para instalación como app.
- ✅ **Diseño Responsive:** Adaptado a móviles, tablets y escritorio.

---

## 🛠️ Tecnologías Utilizadas

| Tecnología | Uso |
|------------|-----|
| **HTML5** | Estructura semántica del sitio |
| **CSS3** | Estilos, variables CSS, Flexbox, Grid, animaciones |
| **JavaScript (Vanilla)** | Lógica del formulario y consumo de API |
| **Groq API** | IA gratuita con modelos Llama 3.3 de Meta |
| **Google Fonts** | Tipografía Orbitron |
| **FontAwesome** | Iconografía vectorial |
| **RealFaviconGenerator** | Generación del paquete de favicons |
